# 🛠️ Nástroje Kvality Online (pro Automotive & Průmysl)

> Moderní, interaktivní a bezplatná sada nástrojů pro inženýry kvality, auditory a manažery výroby podle standardů **IATF 16949** a **VDA**.

[![Spustit nástroje zdarma](https://img.shields.io/badge/Otevřít%20web-NástrojeKvality.cz-0d6efd?style=for-the-badge&logo=googlechrome)](https://nastrojekvality.cz/)

---

## 🚀 Dostupné online nástroje (ZDARMA a bez instalace)

Všechny nástroje běží přímo ve vašem webovém prohlížeči. Data z vaší výroby se neukládají na externí servery a reporty lze okamžitě exportovat do PDF.

| Nástroj | Popis | Odkaz do aplikace |
| :--- | :--- | :--- |
| **8D Report Online** | Kompletní formulář pro reklamace od D1 do D8 s validací opatření a čistým tiskem do PDF. | 👉 [Spustit 8D Report](https://nastrojekvality.cz/8d-report-online) |
| **Paretův diagram** | Automatické generování Paretovy analýzy (pravidlo 80/20) z tabulky neshod z Excelu. | 👉 [Generovat Pareto](https://nastrojekvality.cz/pareto-diagram) |
| **Ishikawa diagram** | Analýza příčin a následků (metoda 6M / rybí kost) s exportem pro zákaznické audity. | 👉 [Vytvořit rybí kost](https://nastrojekvality.cz/ishikawa-diagram) |
| **Cpk / Ppk kalkulačka** | Statistické vyhodnocení způsobilosti procesu, histogram, výpočet PPM a neshodných dílů. | 👉 [Spočítat Cpk](https://nastrojekvality.cz/cpk-kalkulacka-online) |
| **Metoda 5-Why** | Systematické hledání kořenové příčiny problému pro nápravná opatření. | 👉 [Spustit 5-Why](https://nastrojekvality.cz/metoda-5-why) |
| **LPA Checklist** | Vytvoření kontrolního archu pro vrstvené audity procesů (Layered Process Audit). | 👉 [Vytvořit LPA audit](https://nastrojekvality.cz/lpa-checklist-online) |
| **Vývojový diagram** | Tvorba procesních map a diagramů výrobních toků. | 👉 [Kreslit diagram](https://nastrojekvality.cz/vyvojovy-diagram-online) |
| **Časová osa** | Chronologická rekonstrukce sledu událostí pro RCA vyšetřování. | 👉 [Sestavit časovou osu](https://nastrojekvality.cz/casova-osa-online) |
